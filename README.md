# For Stella — 사용 가능한 최종 웹앱

이 폴더의 `index.html`, `finale.html`, `manifest.webmanifest`, `messages.json`, 그림 폴더를 그대로 GitHub Pages에 배포하세요. ZIP 파일만 올리면 안 됩니다.

- 새로 제작된 24장짜리 삽화 컨셉 시트의 서로 다른 각 장면에서 날짜별 그림을 만들었습니다. 이미지 비율을 유지해 표시하므로 화면에서 추가로 잘리지 않습니다.
- 그림 속 짧은 글귀는 손글씨 스타일이며, 편지 본문은 이미지 아래의 HTML 텍스트로 정확하게 표시됩니다.
- 아빠의 24개 원문을 절대 수정하지 않았고, 화면에서 관리용 `01. 아 —` 표식만 숨깁니다.
- 24번째 날이 지나고 24통을 모두 열어야 마지막 연출 버튼이 나타납니다. 마지막 화면은 3초 대기 후 첫 글자가 하나씩 이동해 완성된 문장이 나타나고, 그 다음 가족 야구장 사진이 표시됩니다.
- `매일 저녁 8시 알림 일정 받기`는 남은 일자에 대한 iCalendar `.ics` 파일을 만듭니다. **아이폰 캘린더나 구글 캘린더에 실제로 추가해 알림을 켜야** 동작합니다. 이는 앱 푸시 발송이 아닙니다.
- 진행 정보는 접속한 브라우저 localStorage에만 보관됩니다. 다른 브라우저나 브라우저 데이터 삭제 시 시작 날짜가 초기화됩니다.
- **보안 주의:** GitHub Pages는 공개 페이지이며, JavaScript로 구현한 하루 한 통 제한은 암호화/권한 제어가 아닙니다. 가족 사진과 편지/그림 파일이 링크를 아는 사람 외에도 공개될 수 있습니다. 비공개를 원하면 인증/보안 호스팅을 사용해야 합니다.

## GitHub Pages 업로드
1. `for-stella-GITHUB-UPLOAD.zip`의 압축을 풀고 **폴더 안에 있는 파일과 `illustrations/` 폴더**를 저장소 최상위로 올리세요.
2. 저장소 Settings → Pages → Deploy from a branch → `main` / `/(root)` → Save.
3. `https://YOUR_ID.github.io/YOUR_REPO/` 주소로 접속해 모바일에서 1일 편지와 이미지를 검토하세요.

## 데모/검토
배포용 ZIP에는 전체 공개용 검토 도구가 포함되어 있지 않습니다. 전체 24일을 미리 보기 위해서는 별도 검토 HTML을 사용하세요.
